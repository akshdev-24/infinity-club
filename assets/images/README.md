# Image assets

No original image files could be safely downloaded into this project during this build. The site uses two publicly indexed, venue-specific listing image URLs (gym interior from Trip.com and box-cricket turf from Playo) plus clearly labelled illustrative Unsplash placeholders for the remaining activities.

Replace placeholders with photographs owned by Infinity Club or photographs for which the club has reuse permission. Use these suggested local filenames if you choose to self-host:
- `hero.jpg` — wide, authentic gym/club hero
- `gym.jpg` — gym floor
- `swimming-pool.jpg` — club swimming pool
- `cricket-turf.jpg` — club box cricket turf
- `yoga.jpg` — club yoga class
- `zumba.jpg` — club Zumba/group class
- `martial-arts.jpg` — club martial arts session
- `trainers.jpg` — approved club trainer photo
- `club-interior.jpg` — club interior

Update the corresponding `src` values in `../images.js`, then update matching `src` or CSS `background-image` references in `index.html` and `css/style.css`. Do not present illustrative placeholders as actual club photographs.
